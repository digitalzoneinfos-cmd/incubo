# Incubo — app étudiants + tableau de bord admin

Fichiers :
- index.html : l'app étudiants (installable sur téléphone)
- admin.html : le tableau de bord (adresse : /admin.html)
- config.js : les 2 clés Supabase à coller (vide = mode démonstration)
- supabase-installation.sql : le script à coller dans Supabase > SQL Editor
- incubo-donnees-depart.json : le contenu de départ à importer dans l'admin (Paramètres > Restaurer)

Sans clés dans config.js : mode démonstration, les données restent dans le navigateur.
Avec les clés : tout est partagé en ligne, pour tous les étudiants et toute l'administration.
Le guide pas à pas explique chaque étape.
